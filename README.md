# Работа с базой данных вакансий с hh.ru

## Описание проекта

Эта программа собирает данные о работодателях и вакансиях с платформы [hh.ru](https://hh.ru/), сохраняет их в базу данных PostgreSQL и предоставляет удобный интерфейс для поиска и анализа вакансий.

Программа позволяет:
- Получить список компаний и количество их вакансий.
- Посмотреть все доступные вакансии.
- Узнать среднюю зарплату по всем вакансиям.
- Посмотреть вакансии с зарплатой выше средней.
- Найти вакансии по ключевому слову.

## Структура проекта

```
.
├── main.py # Основной скрипт для запуска программы 
├── src 
│ ├── db_manager.py # Класс DBManager для работы с базой данных 
│ ├── user_interface.py # Интерфейс взаимодействия с пользователем 
│ ├── utils.py # Вспомогательные функции (создание базы данных, загрузка данных) 
│ └── hh_api.py # Получение данных с hh.ru 
├── test 
│ ├── conftest.py # Фикстуры для pytest 
│ └── test_database_connection.py # Тесты подключения к базе данных и функций 
├── requirements.txt # Список зависимостей 
└── README.md # Документация проекта
```

## Как использовать

1. **Установите зависимости:**

```bash
pip install -r requirements.txt
```

2. **Запустите файл `main.py`:**

```bash
python main.py
```

3. **Следуйте инструкциям в консоли:**

Программа предложит вам выбрать действие из списка:

- [1] Компании и кол-во вакансий
- [2] Все вакансии
- [3] Средняя зарплата
- [4] Вакансии с зарплатой выше средней
- [5] Поиск вакансий по ключевому слову
- [0] Выход

## Требования

- Python 3.9+
- PostgreSQL
- Установленные зависимости из `requirements.txt`

## Зависимости

- `psycopg2` — для работы с PostgreSQL
- `requests` — для работы с API hh.ru
- `tabulate` — для красивого вывода таблиц в консоль

## Примечания

- Все данные загружаются в базу `hh_database`.
- Перед каждым запуском база данных пересоздаётся автоматически.
- Программа очищает ключевые слова от лишних пробелов и приводит их к нижнему регистру для удобного поиска.
